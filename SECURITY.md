# Seguridad

## Reportar una vulnerabilidad

Si encontrás un problema de seguridad en metroclaro, **no abras un issue
público**. Escribí a la persona responsable del repositorio o usá
"Report a vulnerability" en la pestaña Security de GitHub.

Incluí, si podés: qué encontraste, cómo reproducirlo y qué impacto tiene.
Respondemos dentro de las 72 horas y te avisamos cuando esté corregido.

No accedas, modifiques ni borres datos de otros, y no hagas pruebas que
afecten la disponibilidad del servicio.
